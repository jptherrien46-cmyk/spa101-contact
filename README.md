# Site contact Spa 101 Mauricie

## Publication gratuite sur GitHub Pages

1. Crée un nouveau dépôt GitHub, par exemple `spa101-site`.
2. Téléverse `index.html`, `styles.css` et `script.js` à la racine du dépôt.
3. Dans GitHub, ouvre **Settings > Pages**.
4. Sous **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche **main** et le dossier **/(root)**, puis clique **Save**.
6. GitHub affichera l'adresse publique du site après le déploiement.

## Domaine spa101.ca

Tu pourras ensuite relier ton domaine à GitHub Pages dans **Settings > Pages > Custom domain**.

## Formulaire

Le formulaire ouvre l'application de courriel du visiteur avec le message déjà préparé. Cela fonctionne sans serveur et sans abonnement.
